# App icons

Generated by [kavanara-icons](https://github.com/KavanaraOrg/kavanara-icons) from
its `icons.json`. Do not edit these files by hand: change the design there, then
download the assets again and replace this folder.

| Folder | For |
|---|---|
| `ios/` | `AppIcon.appiconset` for Xcode (iPhone, iPad, App Store) |
| `android/` | `res/mipmap-*` incl. adaptive and themed layers, Play Store icon |
| `macos/` | `AppIcon.icns` and the `AppIcon.iconset` it is built from |
| `windows/` | `app.ico` and its PNG sizes |
| `web/` | favicons, Apple touch icon, PWA icons and `site.webmanifest` |
